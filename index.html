Large-Scale Analytics + NLP + Forecasting

Customer Complaint Intelligence Platform

An end-to-end intelligence platform built on 15.95M CFPB consumer complaints with chunked preprocessing, Parquet storage, executive analytics, company risk scoring, growth analysis, Prophet forecasting, NLP complaint prediction, and recommendation cards.

Problem

Consumer complaint datasets are large, noisy, and difficult to convert into clear operational decisions. The goal was to build a system that turns complaint volume, company behavior, issue drivers, narratives, and forecast signals into prioritized business recommendations.

Engineering Challenge

The main engineering challenge was handling 15.95M records on a laptop without pretending to have production-scale infrastructure. The solution used chunked processing, aggregation files, and Parquet to keep the workflow practical and explainable.

Approach

  • Processed a large raw CFPB CSV using memory-safe chunked ingestion and Parquet storage.
  • Built executive, product, issue, company, geography, narrative, and channel analytics.
  • Created risk scoring, driver analysis, growth analysis, forecasting, NLP prediction, and recommendation modules.
  • Packaged the dashboard with Docker and added tests and CI proof.

Hybrid RAG + Analytics Engine + Feedback Loop

Enterprise RAG Assistant

A multi-format document assistant that supports PDF, CSV, TXT, JSON, XLS/XLSX, and DOCX files. It combines hybrid retrieval, a schema-aware analytics engine, source attribution, fallback behavior, FastAPI, Streamlit, Supabase feedback, Docker, and GitHub Actions.

Problem

Typical document chatbots struggle with structured tables, hallucination control, and feedback capture. The goal was to build an assistant that can answer semantic document questions and deterministic analytics queries with visible sources.

Engineering Challenge

The hardest part was routing questions correctly. Analytics queries should not rely on LLM reasoning when deterministic Pandas operations are possible, while semantic questions need retrieval, reranking, and source-grounded generation.

Approach

  • Built multi-format ingestion for documents and tables.
  • Implemented a hybrid query router to separate structured analytics questions from semantic RAG questions.
  • Used vector retrieval, BM25, query expansion, reranking, and source attribution for document Q&A.
  • Added feedback capture and analytics through Supabase plus API/UI/Docker/CI proof.

NLP Classification + FastAPI + MLflow

Fake Job Posting Detector

An end-to-end fraud detection project using TF-IDF, Logistic Regression, model comparison, MLflow tracking, FastAPI, Streamlit, Docker, explainability, tests, and CI proof.

Problem

Fake job posts can harm applicants and waste time. The goal was to build an explainable fraud detection system that predicts whether a job posting is genuine or potentially fraudulent using text and structured fields.

Engineering Challenge

The dataset is imbalanced, so accuracy alone was not enough. Fraud precision, fraud recall, fraud F1, ROC-AUC, and interpretability were more important for choosing the final model.

Approach

  • Explored the dataset and fraud patterns across job fields.
  • Built a combined text feature and trained TF-IDF based classification models.
  • Compared Logistic Regression, LinearSVC, and Naive Bayes using fraud-focused metrics.
  • Served the selected model through FastAPI and Streamlit with explainability, MLflow, Docker, tests, and CI proof.
